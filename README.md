Class Management System 🏫

A comprehensive Class Management System built using C++ and Object-Oriented Programming (OOP) principles. This project simplifies classroom operations by integrating key functionalities like assignment management, grading, notifications, quizzes, attendance, and feedback into one streamlined system.

✨ Features

Assignment Management: Submission and grading system for assignments.

Quizzes: Create, attempt, and grade quizzes.

Attendance: Mark and track student attendance.

Marks Management: Record and update student marks.

Notifications: Send important announcements to students.

Feedback System: Facilitate teacher-student feedback for continuous improvement.

🛠️ Tech Stack

Language: C++

Concepts: Object-Oriented Programming (classes, inheritance, polymorphism, encapsulation)
